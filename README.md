# 操作手册

> 这份文档是给你看的。另外两份（`REQUIREMENTS.md` 和 `AI_BUILD_GUIDE.md`）是给 AI 看的，你不需要读懂它们。
>
> 你不需要学写代码。你需要做的是：告诉 AI 要做什么，检查它做得对不对，以及提供图片和文字内容。

---

## 一、第一次开始之前

### 1. 需要装的软件

| 软件 | 用途 | 说明 |
|---|---|---|
| **Google Chrome** | 看效果、展台运行 | 必须。Safari 不行 |
| **GitHub Desktop** | 保存和发布你的修改 | 必须。有图形界面，不用打命令 |
| **你的 AI 编程工具** | 写代码 | 必须能读写本地文件 |

### 2. 把项目下载到电脑

用 GitHub Desktop 克隆仓库。文件夹建议放在"文稿"里，路径中**不要有中文和空格**。

---

## 二、怎么和 AI 一起工作

### 每次开新对话，第一句固定说这个

复制粘贴下面这段：

```
请先读 REQUIREMENTS.md、AI_BUILD_GUIDE.md、PROGRESS.md 和 DECISIONS.md，
然后告诉我现在做到哪一步了，接下来该做什么。
```

AI 会自己搞清楚进度。**不要跳过这一步**，否则它会从零开始瞎做。

### 一次只让它做一个阶段

AI 做完一个阶段会停下来问你。你确认之后它才继续。**不要说"你把全部做完吧"**。一次做太多，出了问题谁也找不到在哪。

### 它问你问题的时候，认真答

一开始 AI 会问你一批关于设计的问题——比如儿童模式面向几岁的孩子、地图图钉点开是弹小卡片还是整屏切换。

这些是你的专业判断，它必须问你。**答不上来就说"你建议哪个"**，让它给方案，你点头就行。

### 三句最有用的话

当你觉得哪里不对，但说不清楚时：

> 这里我看着不对，但我说不清哪里不对。你能做两个不同的版本让我选吗？

当它一次改太多，你跟不上时：

> 太多了，一次只做一件事。

当它说完成了，你想验证时：

> 我应该打开哪个文件、点哪里，才能看到这个效果？

## 三、怎么看效果

双击文件夹里的 `index.html`，会在 Chrome 里打开。

改了东西之后，回到浏览器按 `Cmd + R` 刷新。如果看起来没变化，按 `Cmd + Shift + R` 强制刷新。

---

## 四、怎么自己改内容

**所有文字和图片，都在 `data` 文件夹里的四个文件中。你只需要改这四个。**

| 文件 | 管什么 |
|---|---|
| `ui-text.js` | 界面上的按钮文字、标题 |
| `species.js` | 海洋生物的名字和介绍 |
| `story.js` | 港口故事五个章节 |
| `map.js` | 地图上的图钉 |

用"文本编辑"或者 VS Code 打开。里面长这样：

```javascript
{
  id: "kutai",
  nameMaori: "Kūtai",
  nameEn: "Green-lipped Mussel",
  nameZh: "青口贝",
  ...
}
```

**你要改的是冒号后面、引号里面的内容。** 引号、逗号、括号一个都不能删。

改完保存，刷新浏览器就能看到。

### 如果改坏了

页面变白屏，说明标点被删掉了。两个办法：

1. 在 GitHub Desktop 里右键这个文件，选 `Discard changes`，回到上次保存的状态
2. 把文件发给 AI，说"我改坏了，帮我修"

**改之前先在 GitHub Desktop 里提交一次**，这样随时能退回去。

## 五、怎么加图片

1. 图片放进 `assets/images/` 文件夹
2. 命名用**全小写英文和连字符**，例如 `species-kutai.jpg`。**不要用中文名，不要有空格**
3. 在 `data` 里对应的地方填上路径，例如 `image: "assets/images/species-kutai.jpg"`

### 图片规格

| 用途 | 尺寸 | 大小上限 |
|---|---|---|
| 全屏背景 | 1920×1080 | 500 KB |
| 生物配图 | 1200×1200 | 400 KB |
| 视频 | 1920×1080 | 50 MB |

**大小超标会拖慢加载。** 图片太大时用预览（Preview）打开，导出时降低质量。

⚠️ **单个文件超过 100 MB 就传不上 GitHub。** 视频一定要先压缩。

## 六、怎么保存和发布

在 GitHub Desktop 里：

1. 左侧会列出你改过的文件
2. 左下角输入一句说明，比如"补充了青口贝的介绍"
3. 点 `Commit to main`
4. 点右上角 `Push origin`

一到两分钟后，网站自动更新。

**建议每做完一件事就提交一次。** 提交是免费的，而且是你唯一的后悔药。

## 七、怎么在 iPad 上给老师看

网址是：`https://[你的用户名].github.io/[仓库名]`

### 答辩当天的建议

- **提前一天打开一次**，确认能正常显示
- **答辩前 10 分钟先打开页面**，不要关标签页。万一现场网络不好，已经加载的内容还在
- **开启"引导式访问"**（设置 → 辅助功能 → 引导式访问）。这样页面会锁定在全屏，老师操作时不会误退出
- **把 iPad 调到横屏并锁定方向**

⚠️ 如果刚推送了更新但 iPad 上还是旧的，从屏幕顶部往下拉强制刷新。Safari 的缓存很顽固。

## 八、怎么在展台电脑上运行

1. 把整个项目文件夹拷到展台电脑（U 盘即可）
2. 双击文件夹里的 `启动展示.command`
3. Chrome 会全屏打开，没有地址栏，观众退不出去

**第一次运行会被 macOS 拦下。** 解法：右键点这个文件 → 选"打开" → 弹窗里再点一次"打开"。之后就能正常双击。

退出全屏按 `Cmd + Q`。

### 展示前必做

- 系统设置里关闭**屏幕保护**和**自动休眠**
- 音量调到合适
- 完整点一遍所有页面，确认没有断图

## 九、遇到问题怎么办

### 页面白屏

大概率是刚才改 `data` 文件时删掉了标点。按第四节的办法退回。

### 图片显示不出来

三个可能：文件名拼错了、文件名里有中文或空格、图片没放进 `assets/images/`。

### 毛利语显示成方框

字体不支持长音符号。告诉 AI：

> Tāmure 的 ā 显示成方框了，字体需要换。

### 说不清哪里出了问题

截一张图发给 AI，说清楚"我做了什么操作，然后出现了什么"。截图比描述有用得多。

## 十、必须记住的三件事

**一、毛利语和物种数据，AI 不许自己编。**

所有 te reo Māori 名称、拉丁学名、生态习性，必须是你查证过的。文档里已经写了禁止 AI 生成，但如果你发现界面上冒出了你没提供过的毛利语名字，**立刻停下来核对**。这在新西兰的答辩场合是严重问题。

界面上显示 `[待补充]` 的地方，就是等你填内容的地方。

**二、每做完一件事就提交一次。**

GitHub Desktop 的提交是你唯一的后悔药。

**三、不确定就问 AI，但要问对问题。**

不要问"这样对吗"，它总会说对。

要问：**"我应该点哪里，才能看到你说的效果？"**
